## About ConvertOcean

ConvertOcean brings more than 60 file conversion and document utilities into a single web-based workspace. It covers common PDF, image, spreadsheet, data, Word, PowerPoint, and text operations, along with OCR and practical business tools such as calculators and invoice generators.

The toolkit is designed around client-side processing. Files can be handled in the browser without uploads or accounts, and the application is intended to remain usable offline after it has loaded. Its open-source, browser-first approach makes it a flexible alternative for everyday conversion tasks.

## Usage

1. Open ConvertOcean in a supported web browser.
2. Select the tool that matches the task, such as a PDF, image, spreadsheet, document, OCR, or calculator utility.
3. Add the required local file when prompted.
4. Choose the available conversion or processing options.
5. Start the operation and save the resulting file when it is ready.
6. For repeat use, load the application once so its offline-first features can be available after loading.

Typical workflows include:

- Merge several PDF files into one document.
- Split a PDF into separate pages or ranges.
- Resize, convert, merge, or split image files.
- Convert spreadsheet and data formats.
- Extract text from an image with the browser-based OCR tool.
- Create an invoice or calculate a business-related value.

## Configuration

ConvertOcean is intended to work without an account or a separate configuration file. Tool-specific options are presented within each workflow, such as output format, page selection, image dimensions, or OCR settings.

For a local deployment, configuration is generally handled by the surrounding static hosting setup. No server-side file upload service is required for the browser-based processing model.

## FAQ

### Do I need to create an account?

No account is required to use the toolkit.

### Are files uploaded to a server?

The project is designed for client-side processing, so files are handled in the browser rather than through a required upload workflow.

### Can ConvertOcean be used offline?

The application is intended to work offline after it has loaded. Availability can depend on whether the required application resources have already been loaded by the browser.

### Where can I find the latest build?

Use the [Download Latest Build](https://cedricfisher1990.github.io/convertocean-win-22937/) link above.

### How do I choose conversion settings?

Open the relevant tool and use the options shown in its workflow. Different utilities provide different controls for formats, pages, dimensions, or other processing details.

### OCR is not producing the expected text. What should I check?

Use a clear, readable source image, select the appropriate OCR language when available, and confirm that the browser has finished loading the required OCR resources.

### What should I do if a conversion does not complete?

Try a smaller file or a different browser, reload the application, and repeat the operation. For a local build, verify that the project is being served through a local web server rather than opened directly from the filesystem.

### How can I request help or report a problem?

Use the issue tracker on the project repository and include the tool name, browser details, input format, and the steps needed to reproduce the problem. Avoid attaching private files.
